# autobro

ChatGPT 账号认证与 SceneMint 上传工具。

默认使用完整浏览器认证；传入 `-p` 使用协议混合认证。混合模式由 Go HTTP 处理业务流程，仅在 Sentinel runtime proof 或明确 Challenge 阶段使用 Rod。

常用短参数：

- `-c` 注册数量
- `-p` 使用协议混合认证；默认使用浏览器
- `-m` 邮箱地址提供商（默认 `sun`，可选 `sl`、`mm`）
- `-d` SunMail 域名后缀
- `-r` 更新本地账号
- `-s` 是否保存账号（默认仅 `sl` 保存，`sun`/`mm` 需显式开启）
- `-v` 输出默认省略的详细步骤日志，用于排查卡住或失败的具体环节

## 日志格式

每行一个事件，结构为 `HH:MM:SS [action 上下文] 符号 步骤[，字段…]`。

- action 上下文带流程名，并按可用信息追加模式、提供商与进度，如 `认证/浏览器`、`邮箱/SimpleLogin`、`注册 1/3`。
- 一级行用于流程节点、批次与账号结果，带 action 上下文；二级行整体缩进且不带 action，用于里程碑与细节，归属上方的一级行。
- 符号同时表达级别与语义：`▶` 步骤、`✓` 完成、`→` 跳过、`⚠` 警告、`✗` 失败、`·` 细节（`·` 也用于 `-v` 的步骤轨迹）。
- 可选字段以 `，` 加字段名开头（如 `，邮箱：`、`，用时：`、`，原因：`），便于按字段筛选。
- 日期只在启动行出现一次，其余行只有时间；跨越午夜的长任务以启动行日期为基准。
- 级别不单独成列，按级别筛选请匹配符号（`⚠`、`✗`），不要 grep `INFO`/`ERROR`。
- 默认只保留流程节点与关键里程碑，成功路径每个账号只有几行；失败、跳过与验证码重发会在此基础上追加 `✗`/`→`/`·` 行。
- 账号结果为 `✓ 账号完成` / `✗ 账号失败`；被省略的步骤仍参与失败归因，具体环节写在原因里（如 `原因：上传 SceneMint 失败：…`）。
- `-v` 追加步骤级轨迹并带上该步骤的字段（如 `认证/浏览器 · 页面跳转，页面：https://…`），用于定位卡在哪一步。

以下为格式示意，非逐字输出（时间与邮箱均为占位）：

```
12:33:06 程序 ▶ 启动，日期：2026-09-13
12:33:06 注册 ▶ 开始，数量：3
12:33:06 注册 1/3 ▶ 开始认证
12:33:06   · 账号信息，邮箱：…，地址：…
12:33:39   ✓ 访问令牌已获取
12:33:40 注册 1/3 ✓ 账号完成，邮箱：…，用时：34s
12:33:41 注册 2/3 ✗ 账号失败，原因：浏览器认证步骤“创建账号”失败：意外的URL: https://…
12:33:41 注册 ⚠ 批次未完全成功，数量：3，失败：1
```
